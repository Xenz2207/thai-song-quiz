# Thai Song Quiz

เกมเปิดป้ายและทายเพลงไทย 200 เพลงฮิตจากหลายยุค

## วิธีเล่น

- โหมดเปิดป้าย: เปิดคำใบ้ 1-5 แล้วกดเฉลย
- โหมดทายจากเสียง: ฟังตัวอย่าง 10 วินาที พิมพ์ชื่อเพลง แล้วตรวจคำตอบ
- กดหมายเลขในรายการเพลงเพื่อฟังตัวอย่างเพลงนั้นได้นานสูงสุด 30 วินาที
- กด `♫ เปิดเพลง` เพื่อเปิดหรือปิดเพลงพื้นหลัง

เพลงพื้นหลังสร้างด้วย Web Audio และทำงานออฟไลน์ แต่ browser กำหนดให้ผู้ใช้กดปุ่มก่อนจึงเริ่มเสียงได้ ตัวอย่างเพลงค้นหาจาก Apple/iTunes Catalog และต้องเชื่อมต่ออินเทอร์เน็ต ความพร้อมใช้งานขึ้นกับ preview ที่ Apple มีให้ในแต่ละประเทศ

## เปิดในเครื่อง

เปิด `index.html` ด้วย browser ได้โดยตรง ไม่ต้องติดตั้ง dependency หรือเปิด development server
